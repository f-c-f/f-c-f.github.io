# 工作日志

点击“带入今日未完成任务到明日计划”，将当前日志的今日任务（兼容今日待办）中未完成事项合并到明日计划；保留原任务和已有计划，按任务文字去重，已勾选的明日事项也不会被重新带入。缺少明日计划章节时自动创建，修改先形成本机草稿，沿用 30 秒自动保存。

Tools 登录会话在 30 分钟无操作后过期；有效会话在刷新、返回首页和切换工具时复用，输入与点击会续期，后台检查不会续期。主动退出会立即清除会话。本周已完成任务支持行内 Markdown（含删除线），兼容旧编辑器转义的删除线标记，Markdown 周报导出也会修正该显示；原日志正文保持不变。

历史记录与查询（含日历和搜索）整体默认折叠；每周回顾展开每日记录后按 Markdown 渲染标题、列表、任务、表格、代码和链接，历史详情也采用同样样式。渲染结果经过 DOMPurify 清理，回顾中的复选框只读，编辑需要点击“编辑这天的记录”。每周回顾中未填写项目标签时仅显示日期，历史查询仍显示“未设置项目”，可在编辑区“标题与项目（选填）”中填写项目标签。

当前编辑日志有修改时，每 30 秒自动保存到云端；未修改、空白、离线、会话失效或云端尚未加载时不自动提交。后台保存不锁编辑器，保存期间的新输入保留到下一轮；多设备版本冲突时暂停自动保存并提示核对，刷新成功后恢复。每周回顾和历史查询中的记录默认折叠为日期及项目摘要，展开后才显示正文和编辑入口，展开状态在当前页面更新时保留。本周完成事项汇总也默认折叠。

“今日任务”（兼容旧“今日待办”）中的普通列表和编号列表会在打开编辑时转为待办复选框，原有勾选状态保持不变；其他章节和代码示例不转换，云端正文在手动保存或有修改后的自动保存时更新。Vditor 任务行末按 Enter 继续下一条待办，空待办按 Enter 退出列表；Markdown 备用输入框也支持相同行为。

默认模板为“今日任务 / 进展与记录 / 明日计划”。完成任务只需在今日任务里勾选，不再要求重复填写“今日完成”；具体产出、链接、问题和思考写入进展与记录。日期旁实时显示今日任务完成数。每周回顾及 Markdown 周报自动汇总已勾选完成的今日任务，不统计明日计划中的勾选项。历史“今日待办”标题继续兼容，旧正文不会自动改写；重复插入模板只补齐缺少的章节。

Tools 首页 → 工作日志，路径 `/subsystem/journal/`。沿用 Jekyll subsystem 布局和现有 Tools 密码会话，原 Note 页面及其数据不受影响。

- 页面首先展示当天唯一的 Vditor 编辑框，新的一天默认留白；当天已有内容直接载入，可持续续写与编辑。每日模板为可选操作，标题和项目收在折叠项内。Vditor 3.10.9 加载失败时可使用 Markdown 文本框。
- 自动保存本机草稿；每 30 秒自动或手动保存到 Firebase Realtime Database 的独立节点 `workJournal/YYYY-MM-DD`。
- 云端加载成功后，首次打开当天尚无记录的空日志，自动从昨天“明日计划”提取未完成的任务，生成“今日任务”草稿；已完成项、模板提示项及代码示例不带入。当天已有日志或草稿时不会自动覆盖。昨天无日志时，可手动从最近一篇日志带入，保留当前正文。
- 每天的待办与昨天计划独立，勾选今天不会改变昨天。`carryover.sourceDate` 和 `carryover.importedAt` 随草稿、云端保存及 JSON 备份保留，避免重新打开或清空正文后重复带入。自动带入先形成本机草稿，随后通过 30 秒自动保存或手动保存同步云端。
- “明日计划”兼容普通无序列表、编号列表和未勾选的任务列表，均转换为今日复选框；已勾选的任务仍排除。当天已有正文或草稿时，提供“从昨天日志带入”按钮，手动合并并保留正文，避免为了带入而清空草稿。
- 日历和历史查询位于编辑框下方。日历周一开始，实心圆为保存记录，空心圆为草稿；支持日期查询、补记、项目筛选和全文搜索，展开记录可查看正文，点击其中的编辑按钮回到上方编辑。
- 每周回顾按所选日期所在周展示，含本机草稿；可导出当天、本周 Markdown 及全部 JSON 备份（云端缓存和草稿分别保存）。
- 云端请求有 12 秒超时；首次加载成功后才能云端保存。保存前比较已读版本，并使用 Firebase ETag 条件写入处理多设备冲突。冲突时先导出当天草稿，刷新核对云端内容后合并保存。
- 草稿键 `work-journal-drafts-v1`，云端缓存键 `work-journal-cache-v1`。清理浏览器数据会清理本机草稿，请定期导出。

## 部署与权限

Jekyll 正常构建即可；`scripts/build-tools-ftp.cjs` 和 `scripts/package-tools.mjs` 已纳入新入口。Vditor 的脚本、样式和运行资源使用固定版本 jsDelivr CDN。

当前复用既有 Firebase REST 接口。页面密码只限制前端入口，不构成数据库鉴权；真正私有的数据需要 Firebase Authentication 和相应数据库规则。不要为了让此页可用而放宽数据库全局读写规则。如果 `workJournal` 节点不可读写，页面会提示失败并保留本机草稿。未在开发验证中写入真实云端数据。

记录字段：`date`、`title`、`content`（Markdown）、`projects`（字符串数组）、`updatedAt`（ISO 时间）。Firebase 可能省略空数组，读取时将缺失的 `projects` 视为空数组。
