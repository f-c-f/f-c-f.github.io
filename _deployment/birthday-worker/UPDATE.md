# 生日与日期倒数邮件升级

网页和后台共用 Firebase。新生日和新倒数都写入 `/birthdays`，倒数带 `kind: "countdown"`；已有 `/countdowns` 记录仍可读取、编辑和提醒，无需搬迁或删除数据。

只有 `emailReminder === true` 才发信。新记录默认开启，旧倒数记录若未开启，请在统一列表中编辑、勾选并保存。倒数按完整目标公历日期提前七天、一天及当天提醒，逾期不会每年重复。生日的原规则、已有去重键和每天北京时间 09:00 的定时任务保持不变。

## 已有服务器升级

FTP 全量目录只包含网页，不能更新邮件程序。将本目录单独上传到原生日提醒 VPS 的私有目录，例如 `/root/birthday-reminder-update`，以 root 执行：

```bash
bash /root/birthday-reminder-update/upgrade.sh
```

脚本先运行模拟接口测试，取得原服务的同一把文件锁，备份并替换 `/opt/birthday-reminder/worker.cjs`，再以原服务账户执行 dry-run。验证失败会恢复原程序。不会发送测试邮件，不修改配置、密钥、发送记录或定时器。成功后，已有定时任务下一次执行会使用新程序。

尚未执行此升级时，网页保存开关不代表服务器已支持日期倒数邮件。升级后的 dry-run 也只验证程序和读取，不代表真实邮件已经送达收件箱。
